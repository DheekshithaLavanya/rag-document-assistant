# RAG Document Assistant

A question-answering assistant over PDF documents using Gemini and ChromaDB,
with source citations.

Status: In progress

## Goal
Build a RAG system step by step: working local version first, then
evaluation, better retrieval, and deployment.

## Planned stack
Python, Gemini API, ChromaDB, PyPDF

## Roadmap
- [ ] PDF ingestion and chunking
- [ ] Embeddings and vector storage
- [ ] Question answering with citations
- [ ] Evaluation set
- [ ] Deployment
